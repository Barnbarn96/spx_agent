# Roll Forward the SPX Trading Context Doc

The doc has fixed sections: How we work, Trading rules, Market regime, Recent SPX closes, Key SPX levels, Lessons from recent sessions, Coming up. Keep that structure.

## Steps
1. Search for today's SPX close, high/low, and the main driver; confirm with a second source if snippets conflict.
2. **Recent SPX closes** — add today at the top with a short note; keep ~7 rows, dropping the oldest unless it's a key reference (record close, crash day).
3. **Key SPX levels** — add new reaction highs/lows, remove levels far from price that no longer matter, keep sorted high to low.
4. **Market regime** — update Fed pricing, latest data prints, yields, oil range, AI-trade narrative only where something changed.
5. **Lessons** — add a lesson only if the user states one or confirms one you suggest.
6. **Coming up** — remove past events; add the next data releases, earnings and Fed dates.
7. Update the doc date. Don't change Trading rules unless the user asks.

Update the existing doc in place (or produce the new version in the same format), then summarize what changed in 2-3 lines.
